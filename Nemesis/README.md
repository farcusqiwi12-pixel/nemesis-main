# NEMESIS — public deploy

NEMESIS — 2D HTML simulator of case opening with inventory, market, trading and Socket.IO multiplayer.

## Render: easiest deployment

This repository is prepared for a free Render deployment.

1. Upload/push the project to GitHub.
2. In Render choose **New → Blueprint** and select the repository.
3. Render reads `render.yaml` and creates:
   - a free Node.js Web Service;
   - a free PostgreSQL database.
4. Open the generated `https://nemesis-....onrender.com` URL.

The first start automatically creates the PostgreSQL schema and loads the initial game data. No manual `psql` commands are required.

### Important free-tier limitation

Render's free web service sleeps after 15 minutes without inbound traffic and can take about a minute to wake up. Free Render Postgres currently expires after 30 days, so this setup is intended for testing/hobby use rather than permanent production storage.

## Local launch

```bash
npm install
npm start
```

Set `DATABASE_URL` and optionally `JWT_SECRET` in `.env` first. Redis is optional; rate limiting and online count fall back to memory when Redis is unavailable.

## Render environment

`DATABASE_URL` and `JWT_SECRET` are generated by `render.yaml`. `PORT` is supplied by Render automatically.

## Health check

`GET /health` returns `{ "ok": true }` when the server can reach PostgreSQL.

## Features

- Registration/login with JWT + bcrypt
- Cases and weighted item drops
- Inventory, equipment, filters and sorting
- Player market
- Real-time player trading through Socket.IO
- Reports/moderation
- Daily rewards
- Admin logs
- Redis optional with memory fallback
